# Complex explicit Runge–Kutta methods of orders seven and eight with real projection

Code and data of the paper

> V. Rybin, I. Babkin, A. Karimov, D. Butusov. *Complex Explicit Runge–Kutta Methods of Orders Seven
> and Eight with Real Projection, and Complex Cash–Karp Pairs.* Mathematics (MDPI), [??: year, volume, DOI].

The methods are explicit Runge–Kutta methods with complex coefficients applied to a real system
y' = f(t, y); after every step only the real part of the result is kept. The repository contains the
tableaux CRK7-opt, CRK7-s (seven stages, order seven), CRK8-opt, CRK8-s (nine stages, order eight),
the complex Cash–Karp pair CCK7(6) (eight stages) and the confluent eighth-order scheme L, all with
45 digits; the verification of the order conditions and of the structure of the solution sets; the
minimization of the error constants; all fixed- and variable-step experiments; the C++ timing
benchmark; and the scripts that generate every table and figure of the paper.

## Layout

| Path | Contents |
|---|---|
| `code/` | all scripts (`crk.py`: order conditions and integrator in multiple precision; `tableaux.py`; `problems.py`; `check_tableaux.py`; `measure.py`; `adaptive.py`; `optimize_E.py`; ...) |
| `code/bench/` | C++ timing benchmark (`bench.cpp`, `coeffs.h` generated by `gen_coeffs.py`, `build_bench.bat`) |
| `code/csearch/` | C code of the cascade searches for complex Cash–Karp pairs |
| `data/` | all data; `tableaux.json` holds the coefficients of all tableaux with 45 digits |
| `paper/tables/`, `paper/figures/` | the tables (LaTeX rows) and figures of the paper |

## Running

Python 3.12 with the packages of `requirements.txt`; all scripts are run from `code/`:

```
pip install -r requirements.txt
cd code
python check_tableaux.py
```

Selected entry points:

| Script | What it does |
|---|---|
| `check_tableaux.py` | refines all tableaux, recomputes residuals, error constants, ranks, structure, stability polynomials |
| `rank_mp.py` | multiple-precision Jacobian spectra and local dimensions |
| `confluent.py`, `confluent_mp.py` | the confluent limit of eight-stage tableaux and the scheme L in 90 digits |
| `optimize_E.py`, `front_E.py` | minimization of the error constant under a coefficient bound and the fronts |
| `embedded.py`, `cascade_levels.py` | embedded formulas and the levels of the CCK7(6) cascade |
| `stability.py`, `prefregions.py` | stability and preference regions |
| `measure.py`, `adaptive.py` | fixed-step error constants in 45 digits; variable-step runs |
| `tune_78.py` | tunes a tableau to a given problem by moving along its solution set |
| `make_tables.py`, `figures.py`, `figures_cost.py`, `fig_measured.py`, `make_appendix.py` | regenerate the tables and figures of the paper into `paper/` |

`tableaux.py` builds some early tableaux from the files in `data/search_archive`; the tableaux of the
paper are read from `data/tableaux.json`. The option `crk6`/`cck6` of `cascade_search.py` needs the
code of the order 5–6 repository next to this one. The multiple-precision computations take from minutes
to hours on a laptop; the CPU benchmark needs MSVC and an otherwise idle machine.
